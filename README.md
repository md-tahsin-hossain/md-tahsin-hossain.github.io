# md-tahsin-hossain.github.io

Personal portfolio of Md. Tahsin Hossain — plain HTML, CSS and JavaScript (no frameworks, no build step).

```
index.html                  Home (all sections)
about.html                  About
skills-and-experience.html  Expertise & experience
certifications.html         Certificates (click to view full size)
contact.html                Contact
404.html                    Not-found page (also redirects old capitalised URLs)
assets/                     ALL styles, scripts and images (flat — no subfolders)
  style.css                 All styles
  main.js                   Menu, animations, letters, cursor, certificate viewer
  bg.js                     Animated network background
  *.webp                    Images (skill icons, social, certs, profile, ...)
favicon*, apple-touch-icon.png, web-app-manifest-*.png, site.webmanifest, robots.txt, sitemap.xml
```
